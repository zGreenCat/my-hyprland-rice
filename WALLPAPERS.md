## 🎯 Criterios de Selección

Un buen wallpaper espacial morado debe tener:

✅ **Color dominante**: Morado/Violeta (60%+ de la imagen)
✅ **Contraste**: Buenos contrastes para que los íconos se vean
✅ **Resolución**: Mínimo 1920x1080
✅ **Complejidad**: No muy busy, debe ser relajante
✅ **Estilo**: Cohesivo con tema espacial/lofi
✅ **Calidad**: Sin compresión excesiva

## 🔄 Rotar Wallpapers Automáticamente

### Script para cambiar cada hora
```bash
# Añadir a ~/.config/hypr/hyprland.conf:
exec-once = ~/.config/hypr/scripts/wallpaper-rotation.sh
```

### Crear el script
```bash
#!/bin/bash
# Cambiar wallpaper cada hora
while true; do
    RANDOM_WALL=$(ls ~/Pictures/wallpapers/*.{jpg,png} | shuf -n1)
    matugen image "$RANDOM_WALL"
    sleep 3600  # 1 hora
done
```
