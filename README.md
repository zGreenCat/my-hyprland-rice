# 🌌 My Space Hyprland Rice

Rice personalizado de Hyprland con temática espacial/lofi y colores dinámicos.

## 🎨 Características
- Generación automática de colores con Matugen
- Wallpapers del universo/planetas/lofi
- Palette base morada
- Animaciones suaves y espaciales
- Scripts personalizados
