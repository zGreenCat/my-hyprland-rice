# Migración .conf → Lua (terminada 2026-11-07, Hyprland 0.57.1)

Material histórico. `harness/` y `checklist.py` comparan la config Lua contra los `.conf` legados, que se
eliminaron del repo y de `~/.config/hypr` en la auditoría posterior. Para volver a ejecutarlos, usar el tag
`pre-lua-migration` (última versión con los `.conf`).

`referencia-lua.md` sigue vigente como referencia de la API Lua de Hyprland.
